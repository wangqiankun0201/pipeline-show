# 管道完整性展示平台（PIMS）接口文档 V1.0

> 所有接口经网关统一暴露，前缀 `/api`。网关按 `/api/{服务}/**` 路由并去掉 `/api` 前缀转发。
> 按《梦想云云原生开发实施指导方案》安全规范，仅开放 `GET` / `POST` 方法。
> 鉴权：请求头 `Authorization: Bearer <梦想云令牌>`，网关调用用户中心 `/api/v2/sys/user/currentuser` 校验。

## 0. 统一返回结构

```json
{ "code": "success", "msg": "操作成功", "data": {} }
```

| 字段 | 类型 | 说明 |
|---|---|---|
| code | string | `success` 成功；`fail` 业务失败；`unauthorized` 未登录/令牌失效 |
| msg | string | 提示信息（不含后台调试信息） |
| data | any | 业务数据 |

日期统一 `yyyy-MM-dd` 字符串；数值为 JSON number，缺失为 `null`。

### 0.1 当前用户 `GET /api/auth/currentuser`（网关提供）

返回 `data: { "userId": "...", "loginName": "...", "displayName": "张三", "orgId": "ORG..." }`；令牌无效返回 HTTP 401 与 `code=unauthorized`。本地关闭鉴权时返回“本地开发用户”。

各服务的 Swagger 文档：`http://{服务}:{端口}/swagger-ui/index.html`。

## 1. 管道位置服务 pims-gis（`/api/gis`）

### 1.1 管段列表 `GET /api/gis/segments`

查询参数（均可选）：`mine` 气矿、`pipelineName` 管线、`keyword` 管段名称模糊匹配。

返回 `data: SegmentVO[]`

```json
{
  "segmentId": 5,
  "mine": "重庆气矿",
  "workArea": "万州采输气作业区",
  "pipelineName": "峰汝线",
  "segmentName": "峰汝线A2段",
  "commissionDate": "1990-10-01",
  "outerDiameterMm": 325,
  "wallThicknessMm": 11,
  "materialGrade": "ST45",
  "designPressureMpa": 8,
  "mediumType": "含硫湿气",
  "lengthKm": 8.849,
  "startName": "峰汝线A段 K0+000.0",
  "endName": "峰汝线A段 K8+847.5",
  "startLon": 108.343643, "startLat": 30.71285,
  "endLon": 108.280973, "endLat": 30.666277,
  "coordStatus": "SURVEYED",
  "coordStatusName": "实测坐标",
  "dataSource": "内腐蚀数据.xlsx",
  "geometry": { "type": "LineString", "coordinates": [[108.343643, 30.71285], [108.280973, 30.666277]] }
}
```

`coordStatus`：`SCHEMATIC` 示意坐标（待替换）/ `SURVEYED` 实测坐标。坐标系 WGS84（EPSG:4326）。

### 1.2 管段 GeoJSON `GET /api/gis/segments/geojson`

返回 `data`：标准 GeoJSON `FeatureCollection`，每个 Feature 的 `properties` 为 SegmentVO 去掉 `geometry` 后的字段。

### 1.3 管段详情 `GET /api/gis/segments/{segmentId}`

返回 `data: SegmentVO`。

### 1.4 导入 GIS 数据 `POST /api/gis/segments/geojson/import`

`multipart/form-data`，字段 `file`（.geojson/.json，FeatureCollection，LineString/MultiLineString，WGS84）。
按 `properties.segmentId` 匹配管段，导入后 `coordStatus` 置为 `SURVEYED`。

返回 `data: { "total": 6, "updated": 6, "skipped": 0, "messages": [] }`

### 1.5 地图配置 `GET /api/gis/map/config`

```json
{
  "center": [108.1, 30.6],
  "zoom": 9,
  "basemaps": [
    { "key": "standard", "name": "标准地图", "url": "https://server.arcgisonline.com/ArcGIS/rest/services/World_Street_Map/MapServer/tile/{z}/{y}/{x}", "attribution": "© Esri", "annotationUrl": null },
    { "key": "image", "name": "影像地图", "url": "https://server.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer/tile/{z}/{y}/{x}", "attribution": "© Esri", "annotationUrl": null }
  ]
}
```

底图地址由后端配置（`pims.map.basemaps`），上线内网后切换为天地图/区域湖瓦片服务，前端无需改动。

## 2. 内腐蚀服务 pims-corrosion（`/api/corrosion`）

模型：`d(t)=k·tⁿ`，t = 投运日至计算日天数 / 365.2422。固定参数：峰汝线A2段 (0.22517, 1.07087)、万卧线B段 (0.01697, 1.72263)、万卧线C段 (0.05313, 1.29786)。

### 2.1 基础接口

- `GET /api/corrosion/overview`：六管段、原始内检数量和三预测管段的概览。
- `GET /api/corrosion/segments`：保留六个管段，仅指定三段 predictable=true。
- `GET /api/corrosion/segments/{segmentId}/inspections`：源表内检记录，实测深度单位 mm。
- `GET /api/corrosion/segments/{segmentId}/parameter`：固定 k、n 参数，未纳入预测的管段返回业务错误。
- `POST /api/corrosion/predict`：兼容预测结果结构，计算使用各段固定参数，不生成敏感性情景。
- `POST /api/corrosion/inspections/import`：Excel全量替换，原模板不变。
- `GET /api/corrosion/inner/predict-summary?yearsAfterIli=5`：仅返回指定三个管段，按固定模型计算，供风险服务预填。

### 2.2 两模块报告 `GET /api/corrosion/power-law-report`

返回 `data` 为三个管段报告数组，每项：

```json
{
  "segmentId": 5,
  "segmentName": "峰汝线A2段",
  "commissionDate": "1990-10-01",
  "wallThicknessMm": 11,
  "kValue": 0.22517,
  "n": 1.07087,
  "cutoffDate": "yyyy-MM-dd",
  "comparison": [{ "date": "2011-12-29", "tYears": 21.2434, "measuredDepthMm": 5.94, "calculatedDepthMm": 5.94, "errorMm": 0 }],
  "curve": [{ "date": "1990-10-01", "tYears": 0, "depthMm": 0 }],
  "annual": [{ "year": 2026, "date": "2026-12-31", "depthMm": 0, "stopped": false }]
}
```

示例数值仅表示字段类型，实际值由公式计算。`comparison` 使用两期真实内检日期，errorMm=计算−实测；给定参数为拟合参数，对比不是独立验证。
`curve` 从投运到2031年末，达到壁厚立即截止并补精确交点；不输出超壁厚值、不延长平台线。
`annual` 包含2026—2031各年末，截止后 depthMm=null、stopped=true。

## 3. 失效风险服务 pims-risk（`/api/risk`）

### Gamma 管段列表 `GET /api/risk/gamma/segments`

返回三个适用管段的参数与最新内检状态，包含 `segmentId, segmentName, pipelineName, commissionDate, wallThicknessMm, inspectionDate, inspectionDepthMm, kValue, n, status`。

### Gamma 穿透预测 `POST /api/risk/gamma/predict`

```json
{ "segmentId": 5, "theta": 0.2, "sampleCount": 100000, "seed": 20261029 }
```

支持峰汝线A2段、万卧线B段、万卧线C段。`theta` 范围0.001—5 mm，`sampleCount` 范围1000—200000；默认值如上。数据通过腐蚀服务获取，以最新有效内检实测深度作为条件起点。

返回统一包装中的 `data`：

- 管段及模型快照：`segmentId, segmentName, modelVersion, commissionDate, inspectionDate, wallThicknessMm, inspectionDepthMm, kValue, n, theta, sampleCount, seed, status, warnings`。
- `annual`：2026—2031各年末，字段为 `year, date, tYears, shape, meanDepthMm, cappedMeanDepthMm, remainingWallMm, probability, monteCarloProbability, failedSamples, standardError, confidenceLow, confidenceHigh, zeroFailureUpper95`。所有概率和标准误差均为0—1比例；`meanDepthMm` 为未截断条件均值，`cappedMeanDepthMm` 仅用于物理展示。
- `convergence`：`sampleCount, year, probability, standardError`，比较共享路径前半样本与全样本。
- `history`：`date, measuredDepthMm, calculatedDepthMm`，两轮内检回代检查。

解析结果直接计算 Gamma 上尾 `Q(shape, (wall−dI)/theta)`。蒙特卡洛使用独立时间增量累计路径，固定输入和种子可复现；零事件保留解析值并报告单侧95%概率上限。结果仅表示条件腐蚀穿透概率。

以下为保留兼容的旧版因素和评价接口，其 `PENDING` 策略与 Gamma 计算相互独立。

### 3.1 风险因素定义 `GET /api/risk/factors`

```json
[
  {
    "groupCode": "POF", "groupName": "失效可能性因素",
    "factors": [
      { "code": "predDepthRatio", "name": "预测腐蚀深度比", "unit": "%", "inputType": "number", "source": "CORROSION", "sourceName": "内腐蚀预测", "options": null, "required": true, "min": 0, "max": 100 },
      { "code": "inhibitorDosing", "name": "缓蚀剂投加", "unit": null, "inputType": "select", "source": "CORROSION", "sourceName": "内腐蚀预测", "options": [{"label":"是","value":"是"},{"label":"否","value":"否"}], "required": false, "min": null, "max": null }
    ]
  },
  { "groupCode": "COF", "groupName": "失效后果因素", "factors": [] }
]
```

`source`：`CORROSION` 内腐蚀预测带入 / `GIS` 管段基础数据带入 / `MANUAL` 人工录入。

### 3.2 风险矩阵配置 `GET /api/risk/matrix`

```json
{
  "pofLevels": [ { "level": 1, "name": "极低" } ],
  "cofLevels": [ { "level": 1, "name": "轻微" } ],
  "riskLevels": [ { "code": "LOW", "name": "低风险", "color": "#3BC243" }, { "code": "MEDIUM", "name": "中风险", "color": "#FF9E0F" }, { "code": "HIGH", "name": "较高风险", "color": "#fe377e" }, { "code": "VERY_HIGH", "name": "高风险", "color": "#F35159" } ],
  "cells": [ [ "LOW", "LOW", "MEDIUM", "MEDIUM", "HIGH" ] ]
}
```

`cells[pof-1][cof-1]`，5×5。

### 3.3 管段风险列表 `GET /api/risk/segments`

```json
[ { "segmentId": 5, "mine": "重庆气矿", "pipelineName": "峰汝线", "segmentName": "峰汝线A2段", "predDepthMm": 10.791, "depthRatio": 0.981, "corrosionLimitFlag": "ATTENTION", "pofLevel": null, "cofLevel": null, "riskLevel": null, "riskLevelName": null, "status": "NOT_ASSESSED", "statusName": "未评价", "lastAssessTime": null } ]
```

`status`：`NOT_ASSESSED` 未评价 / `MODEL_PENDING` 模型待接入 / `COMPLETED` 已完成 / `FAILED` 计算失败（取该管段最近一次评价）。

### 3.4 预填输入 `GET /api/risk/segments/{segmentId}/inputs?evaluateYears=5`

返回 `data: { "segmentId": 5, "values": { "predDepthRatio": 98.1, "wallThicknessMm": 11, ... }, "messages": [] }`。
数据经 OpenFeign 获取：管段属性来自 pims-gis，预测深度比和剩余壁厚来自 pims-corrosion 的内检后 N 年预测，环境参数取最近一次非空的内检记录。无法带入时 `messages` 会给出原因。

### 3.5 风险评价 `POST /api/risk/assess`

```json
{ "segmentId": 5, "evaluateYears": 5, "inputs": { "predDepthRatio": 98.1, "mediumType": "含硫湿气", "locationClass": "2" } }
```

后端按因素定义校验：数值类型与范围、选项取值、必填项；未定义的因素编码会被拒绝。

返回 `data: AssessmentVO`

```json
{ "assessmentId": "...", "segmentId": 5, "segmentName": "峰汝线A2段", "assessTime": "2026-10-28 10:00:00", "evaluateYears": 5, "modelCode": "PENDING", "status": "MODEL_PENDING", "statusName": "模型待接入", "pofLevel": null, "cofLevel": null, "pofValue": null, "cofValue": null, "riskLevel": null, "riskLevelName": null, "message": "失效风险计算公式待接入，已保存输入快照（3 项因素）。", "operator": "张三", "inputs": { } }
```

### 3.6 评价记录 `GET /api/risk/assessments?segmentId=5`

返回 `data: AssessmentVO[]`（按时间倒序，最多 50 条）。
