# PIMS 设计说明 V1.0

## 1. 总体架构

```
浏览器（梦想云统一门户携带 token 进入）
   │  /pims（Nginx：静态资源 + /api 反向代理；仅 GET/HEAD/POST）
   ▼
pims-gateway（Spring Cloud Gateway）
   ├─ HttpMethodGlobalFilter   非 GET/HEAD/POST 一律 405
   ├─ AuthGlobalFilter         Bearer 令牌 → 用户中心 currentuser 校验（Caffeine 缓存 5 分钟），
   │                           清除外部伪造的 X-Pims-* 头并向下游透传用户信息
   └─ 路由 /api/{gis|corrosion|risk}/** → lb://pims-{服务}（StripPrefix=1）
        │
        ├── pims-gis        ── PostgreSQL schema pims_gis
        ├── pims-corrosion  ── PostgreSQL schema pims_corrosion
        └── pims-risk       ── PostgreSQL schema pims_risk
               └─ OpenFeign（Sentinel 降级）→ pims-corrosion、pims-gis
Nacos：注册中心 + 配置中心（各服务 Data ID = {服务名}.yaml）
```

- **按业务域拆分**：每个服务有独立 schema，服务间只通过 REST/OpenFeign 交互，不跨 schema 访问。
- **环境隔离**：`local`（H2、无 Nacos、关闭鉴权）/ `dev`、`prod`（`spring.config.import=optional:nacos:{服务}.yaml`）。环境差异配置统一放在 Nacos。
- **微件化**：三个页面各有独立 URL；`/widget/*` 提供无框架页面，便于以 iframe 微件形式发布，并且同样做鉴权校验。

## 2. 数据模型

| 服务 | 表 | 说明 |
|---|---|---|
| pims-gis | `t_pipe_segment` | 管段基础信息（气矿、作业区、管线、管段、投运日期、外径、壁厚、材质、设计压力、介质） |
| | `t_pipe_segment_geometry` | 管段几何（GeoJSON 文本，WGS84）、起止点、长度、坐标状态 `SCHEMATIC/SURVEYED` |
| pims-corrosion | `t_corrosion_segment` | 物理管段：同一“气矿—管线—管段”的多条源记录归并到最小源管段ID |
| | `t_corrosion_inspection` | 《内腐蚀数据.xlsx》逐行（31 列全部保留；如“4.9~5.1”这类区间压力同时保留原文） |
| | `t_corrosion_model_param` | 幂律参数库：`(segment_id, model_version, exponent_n)` 唯一，k 与 n 成组存储 |
| | `t_corrosion_predict_log` | 预测留痕：模型版本、参数快照、请求、操作人、时间 |
| pims-risk | `t_risk_factor` | 风险因素定义（分组、类型、来源、选项、范围），可配置 |
| | `t_risk_assessment` | 评价记录：状态、PoF/CoF 等级与数值、风险等级、输入快照 |

几何目前用 GeoJSON 文本存储，不依赖 PostGIS 扩展。如果后续需要空间查询（缓冲区、相交分析），可以平滑迁移到 PostGIS 的 `geometry(LineString, 4326)`。

## 3. 内腐蚀幂律模型实现

本次采用用户给定的两期内检拟合参数，直接计算 `d(t)=k·tⁿ`。基础信息保留全部五个管段，仅以下三个管段参与预测：

| 管段 | k（mm/年ⁿ） | n | 投运日期 | 壁厚（mm） |
|---|---|---|---|---|
| 峰汝线A段 | 0.22517 | 1.07087 | 1990-10-01 | 11 |
| 万卧线B段 | 0.01697 | 1.72263 | 1989-06-01 | 14 |
| 万卧线C段 | 0.05313 | 1.29786 | 1989-06-01 | 14 |

`t` 为投运日至计算日期的天数 / 365.2422，固定使用给定 k、n，不再按最近内检点重新锚定，也不再计算敏感性指数情景。

- 模块一：在实际内检日期代入公式，与 `实测最大深度比例 × 壁厚` 对比，展示误差表。参数来自两轮内检拟合，此对比属于回代检查。
- 模块二：从投运日到2031-12-31的曲线，突出2026—2031年，可切换只看该区间。年度表取每年12月31日。
- 截止：以 `t_limit=(壁厚/k)^(1/n)` 确定壁厚交点，曲线添加交点后结束。截止后年度表深度为 null，显示停止预测，不绘制壁厚平台线。
- GIS与基础资料保留五个管段。未纳入的两个管段（峰汝线B段、万卧线A段）不生成腐蚀预测，风险预填不沿用旧模型结果。

## 4. Gamma 腐蚀穿透模型

适用于峰汝线A段、万卧线B段、万卧线C段。通过 OpenFeign 获取真实投运日期、壁厚和内检记录，以最新有效内检日期 `TI` 和实测深度 `dI` 为条件起点，输出2026—2031各年末结果。

- 非齐次 Gamma 过程的均值函数为 `k·Tⁿ`，尺度参数 `θ` 默认0.2 mm，形状函数为 `k·Tⁿ/θ`。
- 条件增量 `ΔD(T) ~ Gamma(k·(Tⁿ−TIⁿ)/θ, θ)`；条件深度 `D(T)=dI+ΔD(T)`，均值为 `dI+k·(Tⁿ−TIⁿ)`。
- 极限状态 `g(T)=wall−D(T)`；累计穿透概率为 `Q(k·(Tⁿ−TIⁿ)/θ, (wall−dI)/θ)`。使用上正则化不完全 Gamma 函数直接求上尾，避免 `1−CDF` 消减极小概率。
- 蒙特卡洛按互不重叠时间段抽取独立 Gamma 增量，逐路径累积。默认100000条路径和固定种子20261029，报告事件数、标准误差、95%区间及共享路径前半样本与全样本的收敛对比。
- 零穿透样本不表示真实概率为零；保留解析值，并给出单侧95%上界 `1−0.05^(1/N)`。
- 深度展示曲线在条件均值达到壁厚时补交点并截止；事件判定使用未截断随机深度，概率继续计算到2031年。
- `θ` 表示假定退化离散程度，目前未由现场样本标定；k、n 视为固定参数，内检值视为精确状态，不额外引入测量误差或参数不确定性。该结果是给定模型下的腐蚀穿透概率，不是综合事故概率，也不推算承压能力或后果等级。

旧版因素、矩阵和评价记录接口保留兼容；`PENDING` 策略仍只保存旧版输入快照，不参与 Gamma 页面计算。

## 5. 安全设计

| 规范要求 | 实现 |
|---|---|
| 统一用户中心鉴权 | 网关 `AuthGlobalFilter` + 用户中心 currentuser；前端从 URL 读取 `?token=` 存入 sessionStorage，再通过 Bearer 头携带 |
| 输入校验 | DTO 使用 `javax.validation`（类型、长度、范围）；文件类型和大小校验；风险因素白名单 |
| 防注入 | MyBatis-Plus 参数化查询，不拼接 SQL |
| 隐藏调试信息 | `GlobalExceptionHandler` 只返回通用提示，堆栈只写日志 |
| 禁用危险 HTTP 方法 | 网关和 Nginx 都只放行 GET / HEAD / POST |
| 防伪造身份 | 网关先清除外部传入的 `X-Pims-*` 头，再写入校验后的用户 |
| 日志 | 写在容器标准输出，由梦想云日志中心采集，不暴露在 Web 路径下 |
