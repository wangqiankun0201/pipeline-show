# PIMS 梦想云部署说明

按《梦想云 PaaS 平台应用发布操作手册》和《云原生开发实施指导方案》发布。项目简称 **pims**。

## 1. 命名

| 类型 | 名称 |
|---|---|
| 前端流水线 / 镜像 | `pims-portal-web` |
| 后端流水线 / 镜像 | `pims-gateway-java`、`pims-gis-java`、`pims-corrosion-java`、`pims-risk-java` |
| 镜像版本号 | `${GIT_BRANCH_AS_TAG}_${GIT_COMMIT}` |
| Git 凭证 | `pims-群组名称` |
| 项目主页域名 | `pims.dev.xnyqt.petrochina`（正式环境按泛域名替换） |
| 后端网关域名 | `pims.gw.dev.xnyqt.petrochina` |
| Nginx 配置字典 | `pims-portal-web-niginx-configmap`，键 `nginx.conf` |
| Nacos 命名空间 / Data ID | `pims` / `pims-gateway.yaml`、`pims-gis.yaml`、`pims-corrosion.yaml`、`pims-risk.yaml` |

## 2. 数据库

1. DBA 创建库和用户（示例：库 `pims`，用户 `pims`）。
2. 依次执行 `deploy/sql/01_pims_gis.sql`、`02_pims_corrosion.sql`、`03_pims_risk.sql`（每个脚本会创建自己的 schema）。
3. 脚本由 `python tools/build_sql.py` 根据各服务 `src/main/resources/db/*.sql` 生成。修改表结构时改服务内的脚本，然后重新生成。

## 3. Nacos

把 `deploy/nacos/*.yaml` 导入命名空间 `pims`，修改其中的数据库地址、用户中心地址、Sentinel 地址和天地图 tk。数据库密码等敏感信息用加密配置或 K8s Secret 环境变量（`DB_PASSWORD`）注入。

容器环境变量：

| 变量 | 说明 |
|---|---|
| `PIMS_PROFILE` | `prod`（镜像默认值）或 `dev` |
| `NACOS_ADDR` | 如 `nacos.dev.xnyqt.petrochina:8848` |
| `NACOS_NAMESPACE` / `NACOS_USERNAME` / `NACOS_PASSWORD` | Nacos 访问配置 |
| `DB_PASSWORD` | 数据库密码 |
| `TIANDITU_TK` | 天地图密钥（pims-gis） |

## 4. 后端流水线（Java 模板）

- 执行方式：依次执行；超时 60 分钟；**不配置触发器**；使用 master 分支和 Git 的 https 地址。
- 构建命令（在 `backend` 目录执行，以 pims-gis 为例）：
  `mvn -s ruidao-settings.xml -pl pims-gis -am clean package -DskipTests`
- Dockerfile：`backend/pims-gis/Dockerfile`，构建上下文 `backend/pims-gis`。
- 开启 SonarQube 检查，通过后再打包。
- 应用配置：健康检查路径 `/actuator/health`，间隔 60 秒，超时 30 秒；配置 CPU 超过 85% 时扩容。
- 端口：网关 9100、gis 9101、corrosion 9102、risk 9103。只有网关需要对外暴露（域名访问，80/443 端口）。

## 5. 前端流水线（Node.js 模板）

- 构建命令：`npm install; npm run build`（`.npmrc` 中已指定 registry，内网请改为内网源）。
- **Node 版本**：规范模板为 Node10，但 Vite 5 需要 Node ≥ 18。可以选择平台上更新的 Node 模板（规范注明“随稳定版本逐步迭代升级”）；或者跳过模板构建步骤，直接用 `frontend/pims-web/Dockerfile` 多阶段构建（容器内使用 node:18 编译）。
- 镜像：`frontend/pims-web/Dockerfile`（nginx:1.25-alpine）。
- 创建配置字典 `pims-portal-web-niginx-configmap`，键 `nginx.conf`，值以 `frontend/pims-web/nginx.conf` 为基础，并把 `upstream pims_gateway` 改为网关服务地址；通过存储卷挂载到 `/etc/nginx/nginx.conf`。
- 生产环境变量见 `.env.production`：`VITE_AUTH_ENABLED=true`，`VITE_PORTAL_LOGIN_URL` 改为统一门户登录地址。

## 6. 统一门户与用户中心

1. 在用户中心创建应用，配置菜单：管道位置 `/gis`、内腐蚀趋势预测 `/corrosion`、失效风险计算 `/risk`（作为微件嵌入时使用 `/widget/*`）。
2. 门户以 `https://pims.<泛域名>/gis?token=${token}` 的方式进入；前端读取 token 后移出地址栏，并在之后的请求中通过 Bearer 头携带。
3. 网关 `pims.auth.user-center-url` 配置为对应环境的用户中心地址。

## 7. 数据初始化

- **内腐蚀数据**：首次部署时 `pims.corrosion.seed-enabled: true` 会在检测表为空时自动导入内置的《内腐蚀数据.xlsx》；之后通过页面“导入内腐蚀数据”全量更新（模板列名与原表一致）。
- **GIS 数据**：按 `deploy/templates/pipe-segment-gis-template.geojson` 准备正式坐标（WGS84），在管道位置页面点击“导入GIS数据”，导入后坐标状态变为“实测坐标”。
